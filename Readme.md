# Artistic E-Commerce Platform

A multi-artist marketplace for handmade and custom artistic products.

## Project Structure

- `frontend` - React 19 application
- `backend` - Node.js + Express API
- `docs` - Project documentation

## Technology

### Frontend
- React 19
- JavaScript
- Vite
- Redux Toolkit
- React Router

### Backend
- Node.js
- Express.js
- MongoDB
- Mongoose

## Environments

- Development
- Staging
- Production

## Core Marketplace

- Customers
- Artists
- Administrators
- Categories
- Products
- Custom artwork requests
- Orders
- Payments
- Reviews
